# Soak in Ecstasy

A single-file static page that summarises Vipul Anand's plan to attend Isha's programme, *Soak in Ecstasy of Enlightenment with Sadhguru*, at the Jaipur Exhibition & Convention Centre on Sunday, 10 January 2027.

It is served at `ecstasy.vipulanand.in`. The page is self-contained: one `index.html` with inline CSS and JS, no external requests. It records the event, a shortlisted stay, the three-day rhythm, road and train options, a budget, and the points still open.

**This page is live at [https://ecstasy.vipulanand.in/](https://ecstasy.vipulanand.in/).** It is served by GitHub Pages from the root of the default branch.
